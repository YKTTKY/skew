# Instrument linking: explicit + NLP; macro only to major index ETFs

Articles attach to Instruments via **explicit tickers/cashtags/metadata** plus **NLP entity linking**. Articles with **no** Instrument link never appear on trader-facing surfaces. Broad macro pieces attach only when they **explicitly** mention names/tickers or are clearly about the **market as a whole**, in which case they may link to **major index ETFs** (e.g. SPY, QQQ)—not every equity in a sector. We rejected “link all sector names” (Watchlist noise) and “single-name only” (misses market-wide Pre-Trade Research).
